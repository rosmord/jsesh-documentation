## Appendix C

# Developer's guide

JSesh can be used as a library by Java programmers. The developer's guide comes in two parts, one for each major version of the software:

I'd suggest using the jsesh 8 version for new projects, as there are incompatible changes, and the API is much cleaner.

- [Developer's guide for JSesh 7.x](/developpers_guide/jsesh_7): the previous version of the libraries.
- [Developer's guide for JSesh 8](/developpers_guide/jsesh_8): the new version.
- [Moving from JSesh 7 to JSesh 8](/developpers_guide/jsesh_7_to_jsesh_8): a guide for developers who want to migrate their code from JSesh 7 to JSesh 8.

The [JSesh code repository](https://github.com/rosmord/jsesh) contains a folder called `00_Documents/documentation` with an ongoing programmer's documentation which might be more complete that this one.
