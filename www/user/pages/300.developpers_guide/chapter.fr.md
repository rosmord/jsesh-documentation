### Annexe C

# Guide du développeur

JSesh peut être utilisé comme bibliothèque par les programmeurs Java. Le guide du développeur comporte deux parties, une pour chaque version majeure du logiciel :

- [Guide du développeur pour JSesh 7.x](/developpers_guide/jsesh_7): la série stable actuelle.
- [Guide du développeur pour JSesh 8](/developpers_guide/jsesh_8): la nouvelle version (en construction).
