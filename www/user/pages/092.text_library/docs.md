**Specific to JSesh 8.0 and later**

JSesh distributions used to include a separate folder containing a set of Manuel de Codage texts. 

Due to the changes in the way JSesh is packaged, it becomes difficult to include it as a separate folder. Therefore, it is packaged **inside** the application itself.

We intend to provide a nice navigation system some day, but meanwhile, the way to access the text library is to use the menu **File > Export Text Library**. You choose a destination folder, for instance your desktop or your documents folder, and jsesh will create a `jsesh-texts` folder there with all the texts in the library. You can then open them as normal JSesh files.
